# SmartHomeIot

A full-stack smart home automation platform built with modern web technologies. This project enables intelligent IoT device control, energy management, and real-time data interaction across a secure client-server architecture.

## 🔧 Features

- 💡 Control smart devices from a sleek web interface
- 🔐 Secure architecture with shared logic and modular structure
- 📦 Tailwind CSS for elegant UI design
- ⚙️ Full-stack support with `client/`, `server/`, and `shared/` directories
- ⚡ Uses Vite for lightning-fast development
- 🌐 Real-time data support (designed to be IoT-ready)

## 🧪 Tech Stack

- **Vite** – Lightning-fast frontend tooling
- **Tailwind CSS** – Utility-first CSS framework
- **TypeScript** – Safer, typed JavaScript
- **Node.js / Express** (assumed in `server/`)
- **Modular structure** – `client/`, `server/`, and `shared/`
- *(Optional)* Drizzle ORM if you're using database features

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ManushaLakshanJay/SmartHomeIot.git
cd SmartHomeIot
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
